## List of Programs

About

This repository contains C++ programs based on Object-Oriented Programming (OOP), focusing on Polymorphism and its different concepts.

Programs List

Program 1: Function Overloading

- Demonstrates compile-time polymorphism using functions with the same name and different parameters.

Program 2: Area Calculator Using Function Overloading

- Calculates the area of a square, rectangle, and circle using overloaded functions.

Program 3: Unary Minus Operator Overloading

- Demonstrates overloading of the unary minus operator to negate a number.

Program 4: Prefix and Postfix Increment Operator Overloading

- Demonstrates prefix and postfix increment operators using a counter class.

Program 5: Binary + Operator Overloading

- Demonstrates addition of two complex numbers using the overloaded + operator.

Program 6: Relational Operator Overloading

- Demonstrates comparison of two distance objects using the > operator.

Program 7: Friend/Non-Member Operator Overloading

- Demonstrates operator overloading using a friend function to add an integer and a complex number.

Program 8: Base Pointer Without a Virtual Function

- Demonstrates static binding using a base-class pointer.

Program 9: Base Pointer With a Virtual Function

- Demonstrates run-time polymorphism using virtual functions and base-class pointers.

Program 10: Base Reference With a Virtual Function

- Demonstrates run-time polymorphism using a base-class reference.

Program 11: Abstract Class and Pure Virtual Function

- Demonstrates the use of an abstract class and a pure virtual function.

Program 12: Collection of Polymorphic Shape Pointers

- Demonstrates processing different shapes using polymorphic base-class pointers.

Program 13: Virtual Destructor

- Demonstrates proper destruction of derived objects using a virtual destructor.

Program 14: Object Slicing Demonstration

- Demonstrates object slicing and how references prevent it.

Program 15: Payment Processing System

- Demonstrates run-time polymorphism using different payment methods such as card, UPI, and net banking.

Program 16: Employee Payroll Mini-Project

- Demonstrates salary calculation for permanent and contract employees using polymorphism.

Technologies Used

How to Run

1. Open the C++ file in VS Code.
2. Compile the program using a C++ compiler.
3. Run the executable file to see the output.

Conclusion

These programs help in understanding compile-time and run-time polymorphism, operator overloading, virtual functions, abstract classes, and their practical applications in C++.
